# OnOneBox ERP — Control Panel

لوحة التحكم الإدارية لمنصة **OnOneBox ERP**.

## الهدف
إدارة المنشآت والفروع والمستخدمين والأدوار والصلاحيات ووحدات ERP وقوالب الإعدادات من واجهة عربية RTL.

## التقنية
- React + TypeScript
- Vite
- React Router
- TanStack Query
- MSW للتطوير المحلي
- Tailwind CSS


> طبقة الـ Mock API موجودة للتطوير الأولي، وسيتم استبدالها تدريجيًا بواجهة Backend وقاعدة بيانات متعددة المستأجرين.
